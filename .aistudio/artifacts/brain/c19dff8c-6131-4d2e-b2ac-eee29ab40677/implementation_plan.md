# المرحلة الرابعة: قسم المجتمع التفاعلي ومنظومة الإدارة والبلاغات (Community & Moderation Hub)

بناء **الخانة الرابعة في القائمة الجانبية (مجتمع)** كشبكة تواصل محلية متكاملة تحاكي تجربة فيس بوك وواتساب بهوية **Windows 10 Fluent Design**، مع دورة مراجعة وموافقة مسبقة من المسؤول (Admin)، ونظام بلاغات متقدم للمنشورات والتعليقات، وتحميل تدريجي تلقائي (Infinite Scroll).

---

## User Review & Critical Decisions

> [!IMPORTANT]
> تم تصميم خطة المرحلة الرابعة لتطابق كافة المتطلبات الهندسية والوظيفية المحددة بدقة دون أي نقص:

- **نظام موافقة المسؤول المسبقة على المنشورات**: عند ضغط المستخدم على **"انشر"**، يُحفظ المنشور بحالة `pending` (قيد المراجعة) ويظهر للناشر إشعار/زر واضح يفيد بأن **"يتم عرض المنشور للموافقة عليه من المسؤول"**. عند موافقة الـ Admin ينتشر المنشور للعامة، وعند الرفض تظهر لصاحب المنشور داخل قسم مجتمع رسالة **"تم رفض المنشور"**.
- **الوقت المنقضي بصيغة نصية عربية خالصة**: يُعرض الوقت المنقضي أسفل اسم الكاتب بحجم خط متوسط ومحدث لحظياً بصيغة نصية عربية خالصة (*منذ لحظات، منذ دقائق، منذ ساعة، منذ يوم، منذ أسبوع، منذ شهر*) دون إظهار عداد أرقام للأيام، مع عرض التاريخ الكامل بجانبه.
- **لوحة إدارة المجتمع كشاشة داخلية كاملة (Full Internal View)**: زر **"إدارة"** (الخاص بالـ Admin أعلى يسار شاشة المجتمع) يفتح شاشة داخلية كاملة داخل مساحة العمل (وليست نافذة منبثقة Modal) تضم تبويبي **"موافقة المنشورات"** و**"بلاغات"** مع فلترة البلاغات بين المنشورات والتعليقات وأزرار **"حذف"** و**"استرجاع"**.

---

## 1. Overview & Core Concept

- **What It Does**: منصة تواصل مجتمعي محلية تتيح للمستخدمين نشر الاستفسارات، الاقتراحات، وإعلانات البيع مع دعم كامل للإيموشنات الغنية، التفاعل باللايك والديس لايك، التعليقات والردود المتفرعة مع إيموشنات التفاعل الثلاثة (❤️، 😂، 😢)، ونظام إبلاغ رباعي الخيارات، مدعومة بلوحة رقابة وإدارة داخلية شاملة للـ Admin.
- **Target Audience / Persona**: أهالي المنطقة، التجار، ومستخدمو المنصة الراغبون في تبادل الاستفسارات والاقتراحات وعروض البيع في بيئة آمنة وخاضعة للإشراف.
- **Key Value**: ضمان جودة ومصداقية المحتوى المنشور عبر بوابة موافقة الإدارة ونظام معالجة البلاغات الفوري (حذف أو استرجاع).

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **الفلترة والتحميل التلقائي (Infinite Scroll)**:
     - أعلى يسار شاشة المجتمع قائمة منسدلة للفلترة حسب نوع المنشور: (**الكل، استفسار، اقتراح، بيع**)، وبجانبها للـ Admin زر **"إدارة"** (مع شارة بعدد المنشورات المعلقة والبلاغات النشطة).
     - يعرض النظام **10 منشورات مبدئياً**، وعند النزول إلى أسفل الشاشة يتم تحميل دفعات إضافية تلقائياً عبر مراقب التمرير (`IntersectionObserver` / Scroll Listener).
  2. **إنشاء منشور جديد (بتصميم يحاكي فيس بوك)**:
     - مربع نصي واسع يقبل كافة الحروف والرموز العربية والإنجليزية.
     - **منتقي إيموشنات غني (WhatsApp-style Emoji Picker)** مقسم ومرتب لإدراج الرموز التعبيرية بنقرة واحدة.
     - قائمة منسدلة لتحديد **نوع المنشور**: (`استفسار`، `اقتراح`، `بيع`).
     - زر **"انشر"**: يحول المنشور إلى قائمة انتظار موافقة المسؤول، ويعرض للمستخدم حالة منشوراته المرسلة (**"يتم عرض المنشور للموافقة عليه من المسؤول"** أو **"تم رفض المنشور"** في حال عدم الموافقة).
  3. **بطاقة المنشور والتفاعلات**:
     - رأس المنشور: اسم المستخدم، وأسفله الوقت المنقضي نصياً ومحدثاً لحظياً + التاريخ، وعلى اليسار شارة نوع المنشور (**استفسار / اقتراح / بيع**) وزر **"إبلاغ"** الذي يفتح قائمة منسدلة بـ 4 خيارات:
       1. `إبلاغ عن إساءة`
       2. `إبلاغ عن محتوى غير لائق`
       3. `إبلاغ عن محتوى كاذب`
       4. `الإبلاغ عن محتوى غير صادق`
     - شريط التفاعل: زر **لايك (👍)**، زر **ديس لايك (👎)**، وزر **"أضف تعليق"**.
  4. **التعليقات والردود والإيموشنات التفاعلية**:
     - يظهر أسفل المنشور مباشرة **التعليق الأول أو التعليق المثبت**، مع إمكانية استعراض كافة التعليقات والرد على المنشور أو الرد على تعليق شخص آخر (Nested Replies).
     - بجانب كل تعليق: زر **"لايك"** + 3 إيموشنات تفاعلية محددة: (**قلب ❤️**، **ضحك 😂**، **حزن 😢**) مع عداد لكل تفاعل، بالإضافة لزر إبلاغ عن التعليق.
  5. **شاشة "إدارة" الداخلية الكاملة (لصلاحيات Admin فقط)**:
     - تفتح كشاشة داخلية كاملة مع زر رجوع سريع إلى المجتمع، وتحتوي في أعلاها على خيارين (Tabs):
       - **التبويب الأول (موافقة المنشورات)**: يعرض المنشورات المعلقة وبجانب كل منشور زر **"موافق"** (ينشره فوراً في المجتمع) وزر **"غير موافق"** (يرفضه ويُظهر رسالة **"تم رفض المنشور"** لصاحبه داخل قسم المجتمع).
       - **التبويب الثاني (بلاغات)**: يحتوي على قائمة منسدلة على اليسار للفلترة بين (**"المنشورات"** أو **"التعليقات"**)، ويعرض العناصر المبلغ عنها مع تاريخ وساعة النشر/التعليق ونوع البلاغ، وتحت كل عنصر زر **"حذف"** (حذف نهائي) وزر **"استرجاع"** (إلغاء البلاغ وإعادة العنصر لوضعه الطبيعي).

- **Visual Identity & Theme**:
  - التزام صارم بلوحة ألوان **Windows 10 Fluent Design** الكحلي الداكن (`#0A192F`، `#112240`) والرصاصي المتدرج (`#1E293B`، `#334155`، `#94A3B8`) مع إضاءة الحواف التفاعلية (`fluent-reveal`).
  - منع التمرير الأفقي (`overflow-x: hidden`) ومنع التقريب التلقائي لحقول الإدخال على الهاتف (`font-size: 16px`).

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: صياغة الوقت المنقضي نصياً بدون أرقام أيام**
  - *Chosen Approach*: بناء دالة تنسيق زمني لحظية تحول الفارق الزمني إلى عبارات نصية عربية دقيقة (`منذ لحظات`، `منذ دقائق`، `منذ ساعة`، `منذ ساعات`، `منذ يوم`، `منذ يومين`، `منذ أيام`، `منذ أسبوع`، `منذ شهر`) بجانب التاريخ الفعلي، وتتحدث تلقائياً كل 30 ثانية.
  - *Why*: تنفيذ حرفي لشرط المستخدم بعدم إظهار عداد أرقام للأيام مع الحفاظ على التحديث اللحظي.
- **Decision 2: هيكلة البلاغات الموحدة للمنشورات والتعليقات**
  - *Chosen Approach*: تخزين البلاغات داخل بيانات المنشور والتعليق مع طابع زمني ونوع البلاغ المختار من الخيارات الأربعة، مما يسمح للـ Admin في تبويب **"بلاغات"** بالفلترة الفورية بين المنشورات والتعليقات وتنفيذ **"حذف"** أو **"استرجاع"** بضغطة واحدة.
  - *Why*: يضمن تزامن البلاغات لحظياً عبر Firebase و LocalStorage دون تعقيد أو فقدان للبيانات.

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

```
┌────────────────────────────────────────────────────────────────────────────┐
│                     Community Section (شاشة مجتمع)                         │
├──────────────────────────────────────┬─────────────────────────────────────┤
│   Public Community Feed View         │   Full Internal Admin Management    │
│   (الواجهة العامة للمجتمع)            │   (شاشة "إدارة" الداخلية الكاملة)    │
├──────────────────────────────────────┼─────────────────────────────────────┤
│ • Top Left Filter Dropdown:          │ • Top Tabs Switcher:                │
│   (الكل / استفسار / اقتراح / بيع)     │   1. [موافقة المنشورات]              │
│ • Facebook-Style Post Composer:      │      - Approve ("موافق")            │
│   - Rich Arabic/English Textarea     │      - Reject ("غير موافق" ->       │
│   - WhatsApp Emoji Picker Grid       │        shows "تم رفض المنشور"        │
│   - Post Type Selector               │        to post author)              │
│   - Submit -> Status: Pending Admin  │   2. [بلاغات]                        │
│ • Infinite Scroll Feed (10 initial   │      - Left Dropdown Filter:        │
│   posts + auto-load on scroll end)   │        ("المنشورات" / "التعليقات")   │
│ • Post Card:                         │      - Shows post/comment date,     │
│   - Textual Relative Time + Date     │        time, & 4-type report reason │
│   - Type Badge & 4-Option "إبلاغ"    │      - Actions:                     │
│   - Like / Dislike / Add Comment     │        * "حذف" (Permanent Delete)   │
│ • Comments & Nested Replies:         │        * "استرجاع" (Clear Reports &  │
│   - First/Pinned Comment preview     │          Restore Normal State)      │
│   - Reply to Post or Comment         │                                     │
│   - Like + 3 Reactions (❤️, 😂, 😢)  │                                     │
└──────────────────────────────────────┴─────────────────────────────────────┘
```

- **Data Model Updates**:
  - `CommunityPostType`: `'استفسار' | 'اقتراح' | 'بيع'`
  - `CommunityReportReason`: `'إبلاغ عن إساءة' | 'إبلاغ عن محتوى غير لائق' | 'إبلاغ عن محتوى كاذب' | 'الإبلاغ عن محتوى غير صادق'`
  - `CommunityPostStatus`: `'pending' | 'approved' | 'rejected'`
  - كل منشور `CommunityPostItem` يحتوي على:
    - `postType`: نوع المنشور (`استفسار` / `اقتراح` / `بيع`)
    - `status`: حالة الموافقة (`pending` / `approved` / `rejected`)
    - `likes` و `dislikes`: مصفوفات معرفات المستخدمين
    - `reports`: قائمة البلاغات المرفوعة على المنشور (السبب، المبلغ، التاريخ والساعة)
    - `comments`: قائمة التعليقات، حيث يدعم كل تعليق:
      - `isPinned`: تحديد التعليق المثبت أو إظهار التعليق الأول افتراضياً
      - `likes`: مصفوفة المعجبين بالتعليق
      - `reactions`: تفاعلات الإيموشن الثلاثة (`heart`: ❤️، `laugh`: 😂، `sad`: 😢)
      - `replies`: الردود المتفرعة على التعليق
      - `reports`: البلاغات المرفوعة على التعليق
